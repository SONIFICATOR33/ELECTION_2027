# L’espace image des fiches

Chaque fiche a un cadre réservé à une image : un dessin, une caricature, un pictogramme, ce que tu veux. Tant que le cadre est vide, l’appli affiche le médaillon aux initiales, dans la couleur du parti.

## Ajouter une image

1. Nomme le fichier avec l’identifiant du candidat, en minuscules : `lepen.jpg`, `melenchon.png`…
2. Dépose-le dans ce dossier (`fiches/img/`) sur GitHub : bouton « Add file », puis « Upload files ».
3. C’est tout : l’appli le trouve toute seule à la prochaine ouverture de la fiche.

Formats lus : `.jpg`, `.png` ou `.webp`, dans cet ordre.

## Format conseillé

- Portrait, rapport **4:5** (par exemple 800 × 1000 pixels). Le cadre recadre au centre si le rapport diffère.
- Moins de 300 Ko, pour que la fiche s’ouvre vite sur un téléphone en 4G.
- Un fond uni ou transparent rend mieux dans le cadre doré.

Pour rester serein sur les droits, n’utilise que des images que tu as créées toi-même ou dont la licence autorise la réutilisation.
